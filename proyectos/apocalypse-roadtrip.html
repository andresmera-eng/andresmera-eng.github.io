Apocalypse Roadtrip

🎮 Google Play 📅 2025 ✅ Finalizado
Unity C#

Es un juego de supervivencia y combate vehicular en el que los jugadores deben recorrer una carretera infestada de zombis mientras intentan sobrevivir el mayor tiempo posible. El juego combina gestión de recursos como vida y gasolina, ademas de un sistema de combate automático. El sistema de personalización de los vehiculos ofrece diversas opciones para afrontar los nuevos desafios conforme avanzas, el jugador escoge como quiere sobrevivir.

Mi rol en el proyecto

En este proyecto, participé en el desarrollo de sistemas de supervivencia, combate y progresión en Unity, implementando el comportamiento de enemigos, sistemas de mejoras temporales y permanentes, y escalado dinámico de dificultad. También desarrollé la lógica de interfaces de usuario, indicadores visuales y sistemas de recompensas. Adicionalmente, integré efectos visuales, animaciones y sistemas de audio reactivos para reforzar la experiencia de juego, así como funcionalidades de monetización mediante anuncios recompensados y compras dentro de la aplicación (In-App Purchases).

Desafíos técnicos

En este proyecto tuve mi primer contacto con el sistema de animación mediante texturas 2D de Unity, utilizado en las mecánicas de las armas especiales de los vehículos. También implementé el sistema de partículas para algunos efectos de las armas y para representar el daño recibido por los zombis.

Además, fue el primer proyecto en el que integré anuncios recompensados y un sistema de compras dentro de la aplicación (In-App Purchases). Durante el desarrollo surgieron varios desafíos relacionados con el manejo del audio: las pistas musicales y los efectos de sonido continuaban reproduciéndose incluso cuando el juego estaba en pausa. Asimismo, detecté un inconveniente por el cual, al finalizar un anuncio recompensado, el juego se reanudaba automáticamente aunque originalmente se encontrara en pausa, por lo que fue necesario ajustar la lógica que controlaba ambos sistemas.

Este proyecto también marcó mi primera experiencia utilizando archivos JSON para almacenar y gestionar el progreso del jugador. Mediante este sistema persistí las mejoras realizadas a los vehículos y los recursos obtenidos entre partidas, garantizando que la información permaneciera disponible entre sesiones de juego. Asimismo, fue la primera vez que empleé Scriptable Objects para definir las características y configuraciones de los distintos vehículos, facilitando la organización de los datos y haciendo el proyecto más escalable y fácil de mantener.
